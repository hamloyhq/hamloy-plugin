---
name: plan-a-feature
description: Plan a feature into Hamloy tasks, with subtasks, what waits on what, and the requests and questions only the person can settle, so any agent can pick it up. Use when the person asks to plan, break down or spec out a feature or a change.
---

1. Look first: list with find (two or three of the feature's words) shows whether it is already planned, and what was tried or ruled out.
2. Add one task for the feature, under a heading that names it, with its parts as subtasks. Each title says what will be true when it's done.
3. Anything only the person can do (an account, a key, money, DNS, a deploy) is a request, with exact steps. Anything that is theirs to decide is a question, with options and your recommendation.
4. Set needs on each task that waits on another task, a request or a question, so no agent starts it too early.
5. Tell the person what you added, and which questions and requests come first.
